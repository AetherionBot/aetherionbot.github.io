# Aetherion showcase site

Static landing page for the Aetherion Discord bot. Plain HTML/CSS/JS with no build step.

- `index.html`: short landing page (hero with mock cluster, fact band, four highlights, Premium teaser, CTA).
- `features.html`: alternating feature rows with the Discord-style illustrations, plus a small-features grid. `commands.html`: every slash command with search and filters (cards come from the bot's source).
- `premium.html`: Get Premium (price, free vs Premium table, how to buy, renewals). `faq.html`: FAQ accordions with FAQPage JSON-LD.
- `styles.css`, `script.js`: styling plus command search, filter, click-to-copy and scroll reveal.
- `terms.html`, `privacy.html`: Terms of Service and Privacy Policy (linked from the footer; use these URLs in the Discord Developer Portal).
- `getting-started.html`: five-step setup guide. `changelog.html`: user-facing highlights from the bot CHANGELOG. `404.html`: custom not-found page. All generated by the site generator.
- `assets/logo.webp`: the Aetherion logo mark (the robot profile picture). `assets/robot/*.webp`: the robot mascot poses (transparent, lazy-loaded WebP). `favicon.ico`, `favicon-*.png`, `apple-touch-icon.png`, `android-chrome-*.png` and `og-image.png` (1200x630 share card) are generated from the mascot artwork. `sitemap.xml`, `robots.txt`, `site.webmanifest` for search/install metadata.

The "Add to Discord" buttons (nav on every page, plus the home hero and closing call-to-action) use the OAuth invite
(`https://discord.com/oauth2/authorize?client_id=1545140271073722378&permissions=309576723664&scope=bot+applications.commands`).
"Join our support server" links go to `https://discord.gg/KZjebts36C`. "Message Ori" links open the owner's Discord profile (`https://discord.com/users/1022200760018161684`) for questions and Premium codes.

To host on GitHub Pages, put these files in a repo (or a `docs/` folder) and enable Pages for that branch/folder.
The mock Discord panels are illustrations in HTML/CSS, not screenshots. No tracking scripts.
