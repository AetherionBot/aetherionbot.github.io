Aetherion Dashboard

A web page where server managers can check their Aetherion setup and change it, without typing a command.

Beta

The Aetherion Dashboard is in beta.

Anyone who manages a server Aetherion is in can log in with Discord. You only see servers where you have Manage Server or Administrator and Aetherion is present. Everything in Aetherion keeps working in Discord with slash commands too.

What it does

Setup checklist

The same checklist as /setup status: what is set up, what to fix next and the command that fixes it.

Usage and plan

This month's images and videos, today's AI replies out of the daily limit, Premium status and expiry, and the house wallet.

Change settings

Managers can set the welcome channel, change the welcome card and message (with a live preview), and set the join role and server logs. Administrators manage reaction roles and color roles. With Premium, managers can customize the bot's name, personality and avatar.

Giveaways and polls

Administrators can start a giveaway or a poll with a channel picker, see what is running, and end, reroll, cancel or close it. They are the same giveaways and polls as /giveaway and /poll.

AI channels

Managers choose where Aetherion's AI chat answers: everywhere (the default), only in some channels, or everywhere except some. A channel can also get its own tone, or answer only when someone mentions it or replies to it. Threads follow their channel.

Safe by design

Sign in with Discord. It only asks who you are and which servers you manage. You only see servers you manage, and every change is checked again on the server and logged.
