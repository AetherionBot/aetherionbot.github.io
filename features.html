Features

Everything Aetherion can do

Music, games and server tools are free. Grok AI comes with Premium.

Panels below are illustrations drawn with HTML and CSS, using the bot's real reply text.

Music Free

Music that just works

Play SoundCloud in your voice channel with /play. The now-playing message has buttons anyone in the channel can press.

  • Search a title or paste a SoundCloud link
  • Pause/Resume and Stop buttons
  • Every server plays on its own
Games & Coins Free

Seven games, one wallet

Run /game for the game hub (or /slots and /connect4 for their extra options): blackjack, slots, coin toss, higher-or-lower, trivia, Connect Four and Texas Hold'em poker, all played with Aether Coins.

  • New players start with 5,000 coins
  • Claim 2,000 more with /coins daily (no options), plus a growing bonus for claiming on consecutive days
  • Win, loss or push card with your new balance, plus Same bet, Double and Quit buttons
Giveaways & polls Free

Giveaways and polls, with buttons

Run a giveaway with /giveaway start or ask a question with /poll create. Members press a button; Aetherion does the rest. No AI and no Premium needed.

  • Giveaways: prize, duration, winners and an optional required role, with fair random draws, end early, reroll and cancel
  • Polls: 2 to 10 options, one changeable vote each (or several), live counts and an optional auto-close
  • Saved, so the buttons keep working and timers keep running after a restart
  • Up to 10 of each at a time, from Discord or the web dashboard (beta)
Server tools Free

Roles, logs and a tidy server

Set up the basics in a few commands and let Aetherion handle the routine work. Reaction roles and Customize live in the web dashboard (beta).

  • Reaction roles and 12 gradient color roles, from the web dashboard
  • Autorole, welcome messages and a date channel
  • 25 log events and /purge
Open the web dashboard (beta) →
Grok AI Premium

Grok, in your channels

Mention Aetherion to chat, send images, or talk in voice. Give it a name and personality that only exist in your server.

  • Chat with vision, web and X search
  • Live voice, voice notes and text to speech
  • Custom name, personality and avatar, set in the web dashboard (beta)
