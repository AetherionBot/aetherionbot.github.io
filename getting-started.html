Get started

Set up Aetherion in five steps

From adding the bot to a server that runs itself. Each step takes about a minute.

The five steps

  1. 1

    Add Aetherion to your server

    You need the Manage Server permission. Discord shows the permissions Aetherion asks for, and the FAQ explains each one. It's free to add.

    Add to Discord
  2. 2

    Run /setup status

    Type it in any channel (it needs the Administrator permission). You get a private checklist of what's set up and what isn't, with the exact command to fix each gap. It changes nothing.

  3. 3

    Try /help

    A private tour of every command with a Try it line on each page. Then press play: /play a song from a voice channel, or run /game to open the game hub. Both work right away.

  4. 4

    Set up welcome, autorole and reaction roles

    All free, all for Administrators. Pick what you need:

    • /setup welcome picks the channel for welcome messages
    • /setup autorole gives new members a role the moment they join
    • /reactionrole post makes a panel where people react to pick roles, and /reactionrole colors adds 12 gradient color roles

    Tip: keep Aetherion's role above the roles it hands out, or Discord won't let it assign them. How to fix it.

  5. 5

    Get Premium (optional)

    Premium switches on the Grok AI for your whole server: chat with vision and web search, live voice, images, video and /customize. It's $4.99 a month per server, with no subscription. Run /premium status any time to see your plan and usage.
