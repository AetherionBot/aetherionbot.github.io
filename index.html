How it works

Powered by Grok

Aetherion talks to xAI's Grok through the Responses API and leans on Grok's own abilities (long context, native vision, web and X search, image, video and speech generation) instead of piling on custom memory. Media is delivered straight to the channel, so every request gets one clean reply.

Aetherion is run and maintained by its creator, so there's nothing to host. Add it to your server for free and the non-AI stuff works right away. The Grok features below turn on with Premium.

Setup tip: in Server Settings → Roles, drag Aetherion's role above any roles it should hand out (reaction roles, color roles, auto-role). Discord only lets a bot give roles that sit below its own.

FAQ

Quick answers

Permissions, Premium codes, privacy and more.

Why does Aetherion ask for so many permissions?

Each permission in the invite maps to one feature, like Manage Roles for reaction roles and autorole, View Audit Log for /logs, Change Nickname for /customize name and Connect/Speak for music and voice. See the full list.

How do I redeem a Premium code?

A server admin (Manage Server) runs /premium redeem AETH-XXXX-XXXX with the code you get after paying. More.

What happens when Premium ends?

AI features switch off, free features keep working, and your /customize name and personality pause, then return if you renew. More.

Does Aetherion store my messages?

Only briefly: saved channel messages expire after 3 days, and voice notes are only transcribed when sent to the bot. Read the Privacy Policy.
