Overview ▾
Features

Everything Grok can do, right inside Discord

One bot for conversation, media, voice, music, games and server management.

💬

Chat with Grok

Mention @Aetherion, reply to it, or talk to it directly. Answers come from xAI's Grok via the Responses API (default model grok‑4.3).

👁️

Native vision

Reads images from attachments, embeds, and recent reply-chain pictures, so you can ask about what's on screen.

🔎

Live web & X search

Uses Grok's native web_search and x_search tools when a question needs fresh information.

🎨

Image generation & editing

Generates new images from a prompt or edits an existing one. Can use member avatars and top server emojis as references.

🎬

Video generation

Text-to-video and image-to-video with Grok. Can be switched on or off by the host (ENABLE_VIDEO_GENERATION).

🔊

Text-to-speech

/audio and the Read aloud menu speak text with six Grok voices (Zagan, Eve, Ara, Rex, Sal, Leo), inline tags like [laugh], and styles like whisper.

🎙️

Voice that talks back

/join, say "Aetherion", ask your question, pause. The answer plays back in the same voice channel.

🎵

SoundCloud in the same VC

/play a title or soundcloud.com link, or just say "Aetherion play …". Streams over the same voice connection with ffmpeg.

🪙

Aether Coins economy

Play-money wallets: 5,000 coins to start, a 2,000 coin /daily, a server leaderboard, and a house wallet that starts at 1,000,000.

🃏

Seven casino-style games

Blackjack, slots (three machines), coin toss, higher-or-lower, trivia, Connect Four and Texas Hold'em poker, all with drawn table art.

📊

Profiles, levels & ranks

/profile member cards with a lifetime activity page, /top ranks by messages, voice time or level, and a /server snapshot.

🛡️

Server toolkit

Welcome banners, auto-role on join, 12 gradient color roles via reaction roles, a midnight date channel, 25-event logs, and /purge.

How it works

Powered by Grok

Aetherion talks to xAI's Grok through the Responses API and leans on Grok's own abilities (long context, native vision, web and X search, image, video and speech generation) instead of piling on custom memory. Media is delivered straight to the channel, so every request gets one clean reply.

It's self-hosted: run it with Docker or on Railway using an xAI API key, or sign in with a SuperGrok / X Premium+ account through OAuth. An optional web dashboard shows health, usage and config.

  1. 1

    Mention or reply

    Aetherion activates on a mention, a reply to it, or a clearly directed message, and reads any images in the chat.

  2. 2

    Say “Aetherion” in voice

    Run /join, say the wake word, ask, then pause. The reply plays back in the same channel.

  3. 3

    Play for Aether Coins

    Claim /daily, then take a seat at blackjack, slots, poker and more. It's all play money.
